# 原子助手 · iOS 客户端

[原子助手](https://github.com/xiguac/AtomHelper) 的手机端。它是一个数据源：采集接口拿不到、只有手机本机才有的数据，
上报到你自己的服务器，供助手查询。纯 Swift / SwiftUI，用 XcodeGen 生成工程。

仅自用：自签名安装，不上架，所以用到了一些私有接口。

## 数据

| 类型 | 种类 |
|---|---|
| 持续上报（App 里勾选） | 设备状态、系统信息、网络状态、计步、运动状态、健康摘要、正在播放、音乐库、专注模式 |
| 按次授权（助手提出需求，你在 App 里点同意才采集） | 当前位置、位置轨迹、详细健康记录、运动历史 |

日历、提醒事项、通讯录、邮件走服务器直连（CalDAV / CardDAV / IMAP），不经过这个 App。不读剪贴板、不读相册。

「设置 → 能力探测」会在你的手机上实测每一项能不能拿到。实测被系统拦住的（已安装应用、电池详情、序列号、Wi-Fi 名称、沙盒外的数据库等）已经从代码里删掉。

## 配对

1. 服务器后台「手机」页添加设备，得到二维码和配对码（十分钟内有效，只能用一次）。
2. App 里扫码，或手动填服务器地址（必须 https）和配对码。

## 编译

推送到 `main` 后 GitHub Actions 在 macOS 上编译，产出**未签名**的 `AtomAssistant.ipa`
（Actions 的 artifact 里，同时发布在 Releases 的 `latest`）。再用 WiredResign 自签名安装。

手动运行工作流并勾选 `healthkit`，会多产出一个带 HealthKit entitlement 的 `AtomAssistant-healthkit.ipa`。
免费 Apple ID 的描述文件通常不含 HealthKit，装不上或健康数据读不到时用普通版。

## 限制

- 没有 APNs：服务器无法唤醒 App。授权需求要你打开 App 才会看到；App 在后台被系统唤醒同步时会发本地通知。
- 免费签名每 7 天要重签一次。
- 持续上报只在 App 前台（每 5 分钟）和系统给的后台刷新机会里进行，系统不保证准时。
